# ユーザー管理

`/admin/users`はページング一覧、`/admin/users/{userId}/edit`は基本情報、状態、所属、役職、
直属上司、ロールを管理する。emailは読取専用で外部ID属性を更新しない。

画面のリンク・入力・ボタンは`/api/me.permissions`で制御する。表示を隠すだけではなく、
すべてのBFF転送先Backend APIが対応する権限コードを再検証する。

ユーザー本体と所属更新には`version`を送り、409では「他のユーザーによって更新されています。
最新情報を再読込してください。」と表示する。Frontendの入力補助に加え、期間、主所属重複、
自己上司、無効マスタなどの最終検証はBackendを正本とする。
